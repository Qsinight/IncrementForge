# ADR（架构决策记录）

[TECH_DESIGN 2.3](../TECH_DESIGN.md#23-核心设计决策adr-摘要) 已把 **V1.0 的关键决策**收敛成
`ADR-01`~`ADR-12` 的摘要表（选型 + 理由 + 关联风险），因此本目录**不重复**这些内容。

本目录用于存放两类补充材料：

1. **被摘要表省略的细节**（例如某次选型的实测数据、被否决的备选方案）；
2. **实现期新增的决策**（不改变 2.3 的口径，但需要留下“当时为什么这么写”）。

写 ADR 的规则（沿用 TECH_DESIGN 1.5 的编号体系）：文件名为 `ADR-NN-<短标题>.md`，
正文包含「背景 / 决策 / 备选方案 / 后果 / 关联（章节号、风险号）」五段。

> M1~M3 期间没有新增 ADR：`ui-kit` 与 `persist` 的边界选择、i18n 以 TS 模块而非 JSON 交付，
> 这两条属于**实现取舍**而非架构决策，已写在 [README](../../README.md) 的“M3 的取舍与已知偏差”里。
