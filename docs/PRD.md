# 增量游戏编辑器产品需求文档
- **产品名称**：IncrementForge / 增量工坊
- **文档版本**：V1.0
- **文档状态**：已定稿，不再回填
- **目标平台**：Web 编辑器，导出 HTML 游戏，Json 项目文件/游戏存档

## 核心功能
1. **数学运算**：安全的四则/指对运算，能够在指数级乃至幂塔级数量运算中防止上下溢出；
2. **表达式沙箱**：用户可自行编写常量表达式、条件表达式、赋值表达式；
3. **项目管理**：新建、保存、导入/导出、打包项目，目前为单项目管理，预留多项目管理框架；
4. **资源系统**：添加/修改/删除资源；
5. **生成器系统**：添加/修改/删除生成器；
6. **升级系统**：添加/修改/删除升级；
7. **页面编辑**：添加/修改/删除页面，为每个页面分配资源/生成器/升级条目，调整各条目的排列布局；
8. **预览与模拟**：预览游戏内容，模拟游戏运行；
9. **游戏打包**：导出可运行游玩的 HTML 游戏。

## 页面说明与交互细节
### 工作页面一览
- **顶部标题栏**：左侧显示应用图标及标题，中间显示项目名称，右侧显示“新建”、“保存”、“导入”、“导出”、撤销/重做图标、“打包”。
- **左侧功能区**：由上至下依次显示“资源”、“生成器”、“升级”、“页面”、“设置”。
- **中间工作区**：布局内容视当前所选功能而定。
- **右侧预览区**：显示游戏预览内容，可进行游戏模拟、操作交互。

### 资源工作区
- **左侧资源列表**：顶部栏左侧显示“资源列表”，右侧显示“添加”按钮；资源条目左侧为图标，中间为名称，右侧为表示排序、复制、删除的图标按钮。
- **资源编辑器**：
1. **图标**：系统提供一系列图标作为选择，也可由用户自行上传；
2. **名称**：字符串，修改后立即同步到左侧列表与预览（图标也是）；
3. **描述**：字符串，表示这个资源是做什么的，可被外部引用或赋值；
4. **初始数量**：游戏开局时的初始数量，支持科学计数法和常量表达式，可被外部引用或赋值，尽管可更改，但只在单局存档内有效，“重新开始”后重置；
5. **数量上限**：必定大于零，属于硬上限，超出部分丢弃，支持科学计数法和常量表达式，可被外部引用或赋值；
6. **游戏可见**：布尔值，表示是否在游戏中显示，可被外部引用或赋值。

### 生成器工作区
- **左侧生成器列表**：顶部栏左侧显示“生成器列表”，右侧显示“添加”按钮；生成器条目左侧为图标，中间为名称，右侧为表示排序、复制、删除的图标按钮。
- **生成器编辑器**：
1. **图标**：系统提供一系列图标作为选择，也可由用户自行上传；
2. **名称**：字符串，修改后立即同步到左侧列表与预览（图标也是）；
3. **描述**：字符串，表示这个生成器是做什么的，可被外部引用或赋值；
4. **初始数量**：游戏开局时的初始数量（计入“已购买数量”，会影响价格），支持科学计数法和常量表达式，可被外部引用或赋值，尽管可更改，但只在单局存档内有效，“重新开始”后重置；
5. **数量上限**：可拥有的数量上限，必定大于零，属于硬上限，超出部分丢弃，支持科学计数法和常量表达式，可被外部引用或赋值；
6. **是否禁用**：布尔值，禁用时不可点击、不可购买、不参与生产，可被外部引用或赋值；
7. **游戏可见**：布尔值，表示是否在游戏中显示，不可见时不可购买、不参与生产，可见时恢复，可被外部引用或赋值；
8. **批量购买**：整数，默认为 1，上限为 100，连续购买直到不满足购买价格，亦或是达到批量购买次数，数值为 0 时表示最大购买（无 100 上限），数值小于零时表示自动最大购买（无 100 上限，此时购买不花费材料，即免费购买，但仍要满足最后一件的购买价格；持续购买，若性能开销较大，可隔 N tick 一次，离线时不触发），可被外部引用或赋值；
9. **购买价格**：Json 列表，“购买材料”可为各种资源，“材料数量”支持科学计数法和表达式输入，价格成长通常由“材料已购买数量”的表达式实现，可被外部引用或赋值；
10. **产出资源**：Json 列表，“产出材料”可为各种资源或其它生成器（不影响其价格），“产出数量”支持科学计数法和表达式输入，产出增加由“产出数量”的表达式实现，可被外部引用或赋值；
11. **是否点击器**：布尔值，若是，则取消自动生产，不可购买，改为点击后根据属性“产出资源”获得资源，受“初始数量”影响，点击器可存在多个（仍受“数量上限”的影响），并因此影响“产出资源”，可被外部引用或赋值。

### 升级工作区
- **左侧升级列表**：顶部栏左侧显示“升级列表”，右侧显示“添加”按钮；升级条目左侧为图标，中间为名称，右侧为表示排序、复制、删除的图标按钮。
- **升级编辑器**：
1. **图标**：系统提供一系列图标作为选择，也可由用户自行上传；
2. **名称**：字符串，修改后立即同步到左侧列表与预览（图标也是）；
3. **描述**：字符串，表示这个升级是做什么的，可被外部引用或赋值；
4. **初始数量**：游戏开局时的初始数量（计入已购买数量，会影响价格），支持科学计数法和常量表达式，可被外部引用或赋值，尽管可更改，但只在单局存档内有效，“重新开始”后重置；
5. **数量上限**：可拥有的数量上限，必定大于零，属于硬上限，超出部分丢弃，支持科学计数法和常量表达式，可被外部引用或赋值；
6. **是否禁用**：布尔值，禁用时不可购买、不产生效果，可被外部引用或赋值；
7. **游戏可见**：布尔值，表示是否在游戏中显示，不可见时不可购买、不产生效果，可见时恢复，可被外部引用或赋值；
8. **购买条件**：列表，用户可自行编写条件表达式，默认为真，可被外部引用或赋值；
9. **批量购买**：整数，默认为 1，上限为 100，连续购买直到不满足购买条件或价格，亦或是达到批量购买次数，数值为 0 时表示最大购买（无 100 上限），数值小于零时表示自动最大购买（无 100 上限，此时购买不花费材料，即免费购买，但仍要满足最后一级的购买条件和价格；持续购买，若性能开销较大，可隔 N tick 一次，离线时不触发），可被外部引用或赋值，另外，进行批量购买/最大购买/自动最大购买时，直接结算最后一级的升级效果，因为通常情况下它覆盖了中间的升级内容，而不会产生不可逆效果；
10. **购买价格**：Json 列表，“购买材料”可为各种资源，“材料数量”支持科学计数法和表达式输入，价格成长通常由“材料已购买数量”的表达式实现，可被外部引用或赋值；
11. **每秒生效**：布尔值，表示该升级是否每秒触发一次“升级效果”（重新计算赋值表达式，而非叠加），离线时不触发，可被外部引用或赋值；
12. **升级效果**：Json 列表，“效果前提”为用户可自行编写的条件表达式，默认为真，“效果内容”为用户可自行编写的赋值表达式，“效果数值”为空白数字变量，默认为零，由用户自行赋值（一般为对应效果表达式的计算结果，持久化属性，每个效果独立拥有），只有满足前提，对应效果才可生效，若不满足，则进行下一条判断，每个效果都要进行判断，可被外部引用或赋值，也可创建一个新的升级条目并通过表达式为其赋值（以及添加到指定页面；动态创建，不在编辑器显示，不写进项目文件，但写进游戏存档文件）。

### 页面工作区
- **左侧页面列表**：顶部栏左侧显示“页面列表”，右侧显示“添加”按钮；页面条目左侧为图标，中间为名称，右侧为表示排序、复制、删除的图标按钮。
- **页面编辑器**：
1. **图标**：系统提供一系列图标作为选择，也可由用户自行上传；
2. **名称**：字符串，修改后立即同步到左侧列表与预览（图标也是）；
3. **描述**：字符串，表示这个页面是做什么的，可被外部引用或赋值；
4. **是否禁用**：布尔值，禁用时该页面的所有生成器/升级条目也都禁用（不可购买、产出、生效），但仍可跳转，可被外部引用或赋值；
5. **游戏可见**：布尔值，表示是否在游戏中显示，不可见时该页面的所有条目也都不可见（不可购买、产出、生效，可见时恢复），可被外部引用或赋值；
6. **页面主题**：系统提供一系列主题样式作为选择，也可由用户自行上传；
7. **页面布局**：资源/生成器/升级条目在页面中的布局，网格式，由用户决定列数；
8. **页面条目**：Json 列表，内容为资源/生成器/升级条目，对应的是条目的主题样式，系统提供一系列主题样式作为选择，默认跟随契合页面主题的样式，也可由用户自行上传。

### 设置页面
- **内容**：
1. **编辑器主题**：系统提供一系列主题样式作为选择，也可由用户自行上传；
2. **项目名称**：修改后立即同步到顶部标题栏与预览；
3. **项目作者**：表示这个项目是谁创建的；
4. **项目描述**：表示这个项目是做什么的；
5. **创建时间、最后修改、引擎版本、当前引擎**：不可手动输入，“引擎版本”指项目文件最后修改时记录的编辑器版本，“当前引擎”指当前编辑器的版本；
6. **游戏默认设置**：数字显示格式、逻辑帧率、单帧最大步长、自动存档间隔、是否开启离线收益、离线收益上限。

### 预览区
- **顶部模拟设置栏（不属于游戏内容）**：左侧显示“手机”、“平板”、“自适应”的三选一按钮，中间显示暂停、继续、重新开始的图标按钮，右侧显示时间倍速的下拉框和“解锁全部”（令所有页面、条目可见、取消禁用；一次性动作，后续页面/条目的“游戏可见”、“是否禁用”仍可被覆盖）的按钮。
- **游戏视图**：
1. **顶部标题栏**：显示项目名称；
2. **数据仪表盘**：显示资源的数量、增长速度，下一个可购买条目的预测时间；
3. **资源条目**：卡片式，上部分左侧显示图标，中间由上至下依次显示名称、描述，右侧显示数量；
4. **点击器条目**：卡片式，上部分左侧显示图标，中间由上至下依次显示名称、描述、产量，下部分显示“点击”按钮；
5. **生成器条目**：卡片式，上部分左侧显示图标，中间由上至下依次显示名称、描述、价格、产量，右侧显示已购买数量/拥有数量，下部分显示“购买”按钮；
6. **升级条目**：卡片式，上部分左侧显示图标，中间由上至下依次显示名称、描述、条件、价格、效果，右侧显示已购买数量/拥有数量，下部分显示“购买”按钮，若为动态条目，则右上角显示丢弃的图标按钮；
7. **页面描述**：显示该页面的描述；
8. **底部导航栏**：由左至右依次显示前往各页面的按钮，每个按钮上部分为图标，下部分为名称，最后一个页面为“设置”；
9. **设置页面**：显示项目名称、作者、描述，显示游戏时间（包括离线收益时间）、最后存档，设置数字格式、逻辑帧率、最大步长、存档间隔、开启离线收益（因不触发自动购买和升级的每秒生效，收益低于在线）、离线收益上限，显示“导出存档”、“导入存档”、“重新开始”的按钮。

## 补充
1. 表达式还需要一个随机数函数，该函数在价格表达式中禁用，离线时也禁用。
2. 该产品期望能够处理如购买 1e1e10 数量的生成器/升级、产出同等量级的资源、执行同等量级效果的计算等。
3. 生成器/升级条目具有属性“已购买数量”，下限为零；资源/生成器/升级条目还具有属性“拥有数量”（已购买的以及由其它生成器/升级条目产出的），下限为零，受“数量上限”影响，达到上限后不可购买，直到“拥有数量”再次低于“数量上限”为止；这两个属性可被外部引用或重置为“初始数量”。另外，各条目也可隐含其它必要的属性，一切以便于实现文档需求为准。
4. 升级条目的购买条件列表是 AND 判断，全部为真才可购买；若需要 OR 判断则由用户自行编写表达式实现。
5. 升级条目的每秒生效顺序按`order`稳定排序。
6. 所有被赋值属性的更改在单局存档内都是持久化的（包括值和表达式文本），写入游戏存档，但不写入项目文件，“重新开始”后一切修改复原为项目最开始的时候。
7. 一个条目只能属于一个页面，动态条目在创建时必须指定一个页面。
8. 游戏目前仅为单存档，预留多存档管理框架。
9. 当前版本仅中文，预留多语言框架。
10. 文档中没有明确的事项自行决策，并写入“风险与措施”中。
11. 预览区 2 的数据仪表盘提供展开/收回；预览区 9 的设置页面额外提供“页面主题”选择（跟随页面或系统内置主题），该选择只影响当前游玩/预览的观感，不改写页面的主题设定。
